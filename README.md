# Gitboard

Дашборд над локальными git-репозиториями: состояние веток во всех репозиториях сразу,
заметка к каждой ветке и сводка задач из этих заметок.

Работает без сети и без аккаунтов. Репозитории читаются подпроцессами `git`, заметки
лежат в `~/.gitboard/notes/` обычными `.md`-файлами.

## Экраны

Обзор — репозитории, отсортированные по дате последнего коммита. На карточке текущая
ветка, число веток, сколько из них вмержено и сколько без коммитов дольше заданного
срока. Несколько worktree одного репозитория сводятся в одну карточку.

Ветки — таблица с последним коммитом, автором и статусом: текущая, основная, активная,
вмержена, протухла. Вмерженные приглушены, это кандидаты на удаление.

Заметка — блочный редактор, блоки вставляются по `/`: заголовки, списки, чекбоксы, код,
цитаты. Содержимое пишется в markdown и сохраняется автоматически.

Сегодня — незакрытые чекбоксы с датой из всех заметок, сгруппированные по «Просрочено»,
«Сегодня» и «Дальше».

## Задачи

Задача — markdown-чекбокс в заметке, дата ставится через `@`:

```markdown
- [ ] поправить дату в баннере @2026-08-28
- [ ] обновить сертификат @01.09
- [x] сделано
```

Распознаются форматы `ГГГГ-ММ-ДД` и `ДД.ММ`, во втором подставляется текущий год.
Чекбокс без даты остаётся в заметке, но в сводку не попадает.

## Установка

Сборки для macOS и Windows — на [странице релизов](https://github.com/odemaru/gitboard/releases).
Требуется `git` в PATH; при его отсутствии приложение выводит сообщение вместо пустого экрана.

Сборки не подписаны сертификатом разработчика, поэтому первый запуск нужно подтвердить.

macOS: начиная с версии 15 правый клик → «Открыть» диалог Gatekeeper не обходит. Снять
карантин можно командой

```bash
xattr -dr com.apple.quarantine /Applications/Gitboard.app
```

либо через «Системные настройки» → «Конфиденциальность и безопасность» → раздел
«Безопасность» → «Открыть всё равно».

Windows: SmartScreen → «Подробнее» → «Всё равно выполнить».

## Настройка

`~/.gitboard/config.json`:

```json
{
  "roots": ["/Users/me/projects"],
  "maxDepth": 3,
  "staleDays": 60
}
```

По умолчанию обходится домашняя папка на глубину 3. Результат обхода кэшируется, поэтому
полное сканирование файловой системы происходит только при первом запуске. `staleDays` —
срок без коммитов, после которого ветка считается протухшей.

Те же параметры правятся на экране «Настройки».

## Разработка

```bash
npm install
npm run dev        # сервер :4317 и Vite :5173 с горячей перезагрузкой
```

```bash
npm start          # собрать фронт и поднять на http://localhost:4317
npm run desktop    # запустить как десктопное приложение
npm run dist:mac   # dmg и zip под macOS
npm run dist:win   # установщик и zip под Windows
```

## Устройство

```
server/git.js      обход папок, ветки, worktree, merged и stale
server/store.js    конфиг, реестр репозиториев, заметки, разбор задач
server/index.js    HTTP API
web/               React и Vite, Material Design 3
desktop/main.js    Electron, поднимает тот же сервер внутри себя
```

Заметка адресуется путём ветки: `feat/login` в репозитории `myapp` лежит в
`~/.gitboard/notes/myapp/feat/login.md`. Файлы правятся любым редактором, ищутся грепом
и синхронизируются отдельным репозиторием.

## Безопасность

Приложение не обращается в сеть: нет ни телеметрии, ни проверки обновлений, ни запросов
к хостингам репозиториев.

Сервер слушает `127.0.0.1` и принимает запросы только с локальным заголовком `Host`.
Без этой проверки сторонний сайт мог бы через перепривязку DNS оказаться для браузера
тем же источником, что и локальный сервер, и прочитать пути к репозиториям и содержимое
заметок.

Имена веток и идентификаторы репозиториев проверяются посегментно, поэтому ветка вида
`../../` не выводит запись за пределы каталога заметок.

Сборки не подписаны, происхождение бинарников операционная система не подтверждает.
Альтернатива — собрать из исходников: `npm install && npm run dist:mac`.

## Планы

- Лента коммитов по репозиторию и ветке, с диффом и поиском по сообщениям
- Фоновый `fetch`, чтобы «вмержена» и «протухла» считались по origin, а не по локальным ссылкам
- Незакоммиченные изменения на карточке репозитория
- Удаление вмерженных веток пачкой, переключение и подтягивание из интерфейса
- Открытые pull request рядом с ветками; потребует токен, который будет храниться в системном keychain
- `@`-упоминания веток и коммитов в редакторе, обратные ссылки между заметками
- Дата задачи отдельным элементом вместо текста `@2026-08-28`
- Поиск по заметкам
- Системные напоминания о задачах на сегодня
- Тёмная тема
- Подпись сборок сертификатом разработчика и нотаризация
