# Gitboard

Локальный дашборд над всеми твоими git-репозиториями. Показывает, где что происходит,
какие ветки пора снести, и даёт к каждой ветке заметку в блочном редакторе — с задачами,
которые собираются в один список «Сегодня».

Всё работает на твоей машине. Никаких токенов, аккаунтов и запросов наружу:
данные читаются локальным `git`, заметки лежат в `~/.gitboard/notes/` обычными `.md`-файлами.

## Что умеет

**Обзор репозиториев.** Обходит папки, находит все репозитории и сортирует по свежести
коммита. На карточке — текущая ветка, сколько веток, сколько уже вмержено и сколько
протухло. Worktree одного репозитория схлопываются в одну карточку.

**Ветки.** Полный список с последним коммитом, автором и статусом: активная, основная,
вмержена, протухла. Вмерженные приглушены — это те, которые можно удалять.

**Заметка по ветке.** Notion-подобный блочный редактор: заголовки, списки, чекбоксы,
код, цитаты — по `/`. Сохраняется автоматически в markdown.

**Сегодня.** Все незакрытые чекбоксы с датой из всех заметок, сгруппированные по
«Просрочено / Сегодня / Дальше».

## Задачи

Задача — это обычный markdown-чекбокс в заметке. Дата пишется через `@`:

```markdown
- [ ] поправить дату в баннере @2026-08-28
- [ ] обновить сертификат @01.09
- [x] уже сделано
```

Понимает `@ГГГГ-ММ-ДД` и `@ДД.ММ` (год подставится текущий). Чекбокс без даты живёт
в заметке, но в сводку «Сегодня» не попадает.

## Установка

Скачай сборку для своей системы со [страницы релизов](https://github.com/odemaru/git_digest/releases).

Сборки не подписаны сертификатом разработчика, поэтому при первом запуске система
поругается — это ожидаемо.

**macOS.** Появится «Apple не удалось подтвердить, что файл не содержит вредоносного ПО».
Начиная с macOS 15 правый клик → «Открыть» этот диалог больше не обходит. Работают два пути:

```bash
xattr -dr com.apple.quarantine /Applications/Gitboard.app
```

Либо через интерфейс: «Системные настройки» → «Конфиденциальность и безопасность» →
пролистать до раздела «Безопасность» → строка про заблокированный Gitboard →
«Открыть всё равно».

**Windows.** SmartScreen покажет «Windows protected your PC» → «Подробнее» →
«Всё равно выполнить».

Нужен установленный `git` в PATH — приложение скажет, если его нет.

## Настройка

При первом запуске обходится домашняя папка на глубину 3. Если репозитории лежат
в другом месте или обход долгий — поправь папки в «Настройках».

Конфиг: `~/.gitboard/config.json`

```json
{
  "roots": ["/Users/me/projects"],
  "maxDepth": 3,
  "staleDays": 60
}
```

`staleDays` — через сколько дней без коммитов ветка считается протухшей.

## Запуск из исходников

```bash
npm install
npm run dev       # сервер :4317 + Vite :5173 с горячей перезагрузкой
```

Другие команды:

```bash
npm start         # собрать фронт и поднять на http://localhost:4317
npm run desktop   # собрать фронт и запустить как десктопное приложение
npm run dist:mac  # собрать .dmg и .zip под macOS
npm run dist:win  # собрать установщик под Windows
```

## Как устроено

```
server/    Fastify + обёртка над git; вся работа через подпроцессы git
  git.js     обход папок, ветки, worktree, merged/stale
  store.js   конфиг, реестр репозиториев, заметки, парсинг задач
  index.js   HTTP API
web/       React + Vite, Material Design 3
desktop/   Electron: поднимает тот же сервер внутри себя
```

Заметки адресуются путём: ветка `feat/login` в репозитории `myapp` лежит в
`~/.gitboard/notes/myapp/feat/login.md`. Их можно править любым редактором,
искать грепом и синхронизировать приватным репозиторием.

## Планы

Чего пока нет, примерно в порядке пользы:

**Git, которого не хватает**
- Лента коммитов по репозиторию и по ветке, с диффом и поиском по сообщениям
- `fetch` в фоне, чтобы «протухла» и «вмержена» считались по origin, а не только по локальным ссылкам
- Незакоммиченные изменения прямо на карточке репозитория
- Действия над ветками из интерфейса: снести все вмерженные пачкой, переключиться, подтянуть

**Pull requests**
- Открытые PR с GitHub и GitLab рядом с ветками: статус ревью, проверки, кто ждёт ответа
- Потребует токен — первый случай, когда приложение пойдёт наружу, так что строго по желанию
  и с хранением в системном keychain, а не в конфиге

**Редактор**
- `@`-упоминания веток и коммитов с автодополнением, обратные ссылки между заметками
- Дата задачи отдельным чипом вместо текстового `@2026-08-28`
- Поиск по всем заметкам

**Остальное**
- Системные напоминания о задачах на сегодня
- Тёмная тема
- Синхронизация `~/.gitboard/notes/` приватным репозиторием — заодно даёт доступ с телефона
- Подпись сборок сертификатом разработчика и нотаризация, чтобы не обходить Gatekeeper руками

## Безопасность

Приложение не ходит в сеть: ни телеметрии, ни обновлений, ни запросов к GitHub.
Всё, что оно делает — запускает `git` подпроцессами и пишет markdown в `~/.gitboard/`.

Сервер слушает только `127.0.0.1` и принимает запросы лишь с локальным заголовком
`Host`. Без этой проверки вредоносный сайт мог бы через перепривязку DNS стать для
браузера «одного происхождения» с локальным сервером и вычитать пути к репозиториям
и содержимое заметок.

Имена веток и идентификаторы репозиториев проверяются посегментно, чтобы ветка
вида `../../` не увела запись за пределы каталога заметок.

Сборки не подписаны сертификатом разработчика — это значит, что операционная система
не может подтвердить их происхождение. Если это неприемлемо, собирайте из исходников:
`npm install && npm run dist:mac`.
